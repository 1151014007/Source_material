# 工作台视觉调整

工作台以内容、状态和操作为中心，采用深色产品界面，参考 [Linear 官方工作区截图](https://linear.app/docs/conceptual-model)。视觉选择包括深色主题、统一布局密度和清晰的主次文字层级。

登录、接入概览、成员管理统一使用炭灰色背景、细分隔线、小圆角、线性 SVG 图标及少量紫灰强调色。移除登录宣传插画、英文标语和大面积彩色指标卡。侧栏保留当前可用页面；列表与状态直接展示后端数据。

服务接入支持本地搜索和验证状态筛选。筛选只处理已返回的数据，不增加后端请求。配置已填写、验证通过、验证失败、尚未验证分别显示；已有会话、CSRF、角色和退出登录逻辑保留。

沿用 React、TypeScript、Vite 与现有依赖，无外部字体、图片或新增运行依赖。窄屏使用图标侧栏，宽表格在自身容器内滚动。验证包含现有前端回归、搜索与筛选新增回归、生产构建及本地浏览器检查。未执行收费模型测试，未推送远程仓库。

## 用户反馈后的第二轮

设计方向为“工作台与官网结合，以工作台为主”。参考官方设计重构文章中的环境、外观、层级与对齐，以及官网品牌呈现；不把小字、黑底当成设计目标。

第二轮在现有可用功能内重做：导航框架与内容画布分层，列表使用更可读的字号、主次文字和状态语义；服务商并入能力信息，完整属性按需在详情面板查看（桌面非模态、窄屏模态并限制焦点）。刷新保留当前结果及筛选，失败保留的数据明确标识为旧结果，健康检查失败不沿用旧绿色。搜索支持 `/` 聚焦、`Esc` 清空；详情关闭恢复触发按钮焦点。手机保留能力与验证结果，完整模型在详情中查看。

官网视觉只用于登录入口的映库字标、原创 M 标识、轻微空间光感和排版留白，不把宣传图形搬入工作列表。这些设计用于区分品牌入口与日常工作界面。尚未完成的素材业务继续按原计划开发，不制造可点击的假入口。
