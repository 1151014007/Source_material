# 工作台视觉调整

用户希望按 Linear 风格直接试改现有前端，降低装饰感，先看实际效果。本次采用深色产品界面，参考 [Linear 官方工作区截图](https://linear.app/docs/conceptual-model)。深色主题、布局密度与字体为本次实现选择，尚未得到用户对最终视觉效果的反馈。

登录、接入概览、成员管理统一使用炭灰色背景、细分隔线、小圆角、线性 SVG 图标及少量紫灰强调色。移除登录宣传插画、英文标语和大面积彩色指标卡。侧栏保留当前可用页面；列表与状态直接展示后端数据。

服务接入支持本地搜索和验证状态筛选。筛选只处理已返回的数据，不增加后端请求。配置已填写、验证通过、验证失败、尚未验证分别显示；已有会话、CSRF、角色和退出登录逻辑保留。

沿用 React、TypeScript、Vite 与现有依赖，无外部字体、图片或新增运行依赖。窄屏使用图标侧栏，宽表格在自身容器内滚动。验证包含现有前端回归、搜索与筛选新增回归、生产构建及本地浏览器检查。未执行收费模型测试，未推送远程仓库。
