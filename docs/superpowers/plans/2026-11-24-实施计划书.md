# 多模态素材平台实施计划书 / Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 当前仅提交计划，不开始执行。

**Goal:** 交付独立仓库、独立部署、可处理文档/图片/音频/视频并支持跨模态检索、审核发布与引用问答的素材平台。

**Architecture:** 模块化 FastAPI 单体负责业务与鉴权，Celery Worker 负责耗时处理；PostgreSQL 保存业务、任务、版本和两种向量索引，私有 TOS 保存文件。通过事务 Outbox 连接数据库和队列，通过发布快照连接审核与检索，通过服务账号连接数据中台与客服。

**Tech Stack:** Python 3.12 / FastAPI / SQLAlchemy 2 / Alembic / PostgreSQL 17 + pgvector 0.8 / Redis 7 + Celery 5 / React 18 + TypeScript + Vite / FFmpeg / pypdf + pypdfium2 / RapidOCR / TOS / 百炼云模型。实施时锁定实际可用依赖与镜像摘要。

- 自动检测与空遮罩不能直接认定脱敏成功；对外检索使用已审核发布件重新提取的内容；敏感音视频/PDF 以替换发布件完成审核。
- CI 使用云接口替身；发布前必须另做真实云模型与 TOS 验收，不以替身测试宣称 AI 能力已通过。
- 环境模板只放占位值；实际密钥放本地 `.env` 或部署 secrets；保留第三方来源说明，不迁移私人数据和旧真实凭据。

## 1. 交付范围与业务验收

| 使用场景 | 首版必须做到 | 验收方式 |
|---|---|---|
| 找图片 | 自然语言与上传图片都能检索视觉内容 | 删除人工同名标签后仍命中标注样例 |

| 项目交付 | 新仓库、启动、测试、CI、README | 干净环境按文档可运行；有真实云验收记录 |

## 3. 共用协议与任务依赖

在 T01 的 `backend/app/domain/contracts.py` 固定以下命名，后续任务使用同一协议，不临时发明相似字段：

| 类型 | 固定字段 |
|---|---|

| `AssetVersionRef` | `asset_id: UUID, version_id: UUID` |

| `ProcessingResult` | `segments: list[SegmentDraft], derivatives: list[DerivativeRef], warnings: list[str]` |
| `PipelineContext` | `version_id: UUID, stage: str, recipe_version: str, config_hash: str, lease_id: UUID` |
| `EmbeddingBatch` | `model_space: str, dimension: int, vectors: list[list[float]], usage: dict` |
