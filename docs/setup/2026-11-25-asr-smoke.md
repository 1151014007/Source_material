# Token Plan 语音识别实测

时间：2026-11-25，Asia/Shanghai。用户要求检查并测试可用语音模型。

| 检查 | 实测结果 |
|---|---|
| 模型 | qwen-audio-3.0-asr-flash |
| 凭据 | 用户现有Token Plan密钥，未输出密钥 |
| 接口 | POST /api/v1/services/aigc/multimodal-generation/generation |
| 输入 | 本机Windows Huihui合成的中文短音频，非用户私人录音 |
| 格式 | WAV，16kHz，16bit，单声道 |
| 本地时长 | 8.792秒 |
| HTTP状态 | 200 |
| 文本核对 | 忽略标点后，与预设测试文本一致；标点/断句存在变化 |
| 时间戳 | 13组词级起止时间，均为合法毫秒范围 |
| 示例 | “你好”200–680ms；“这是”1040–1400ms；“语音”1400–1880ms |
| 供应商报告处理时长 | 8秒 |

原始测试文本：你好，这是语音识别测试。视频上传后，可以按照台词搜索对应片段。

实际返回文本：你好，这是语音识别测试视频。上传后可以按照台词搜索对应片段。

结论：当前账号的该ASR模型已完成一次真实连通、中文转写和词级时间戳验证；不代表长音频、噪声、多说话人或端到端视频检索已经验收。

原配置paraformer-v2为之前的候选，更新为本次实测模型；聊天与向量密钥、地址保留。语音接口不拼在聊天compatible-mode/v1路径下。长音频需依据单次输入限制设计分段与绝对时间合并，并专门测试，不以短音频结果推断全量效果。
